# Code of Conduct

GeoViz is an educational project. Participation should make learning safer, clearer, and more enjoyable for everyone.

## Expected behavior

- Be respectful, patient, and specific in technical discussion.
- Critique ideas and code, never people.
- Welcome questions and explain mathematical assumptions.
- Give credit for prior work and disclose copied or adapted material.
- Prefer reproducible evidence—tests, examples, or references—over authority.

## Unacceptable behavior

Harassment, discrimination, personal attacks, deliberate misinformation, plagiarism, and publishing private information are not accepted in project spaces.

## Enforcement

Maintainers may edit or remove inappropriate contributions and restrict participation when necessary. Report concerns privately to the repository owner.
