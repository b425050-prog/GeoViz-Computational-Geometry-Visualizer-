# Three-minute OOP project demonstration

1. Open the portable application. F2 -> Reference scene -> Enter -> Space. Seek the desktop timeline;
   explain a recorded pseudocode line and the frozen Run/Frame relationship.
2. F4 to Dijkstra or A*, select a route sample, Run, then C. Compare two frozen algorithms on the same
   input and read the cost/frontier/parent rows. Explain Strategy and shared route inheritance.
3. Move a point or edit a setting. Show invalidation, Ctrl+Z/Y, and the Lab/security/Lab roundtrip.
   Ctrl+S saves an independently named session. Explain the Memento input history and recovery files.
4. Open Security features, Run, inspect one noise point. F8 compares plausible parameters. Record a
   review with a note, export evidence, and distinguish sample truth, analyst judgement and reasons.
5. Show the const SecuritySettings interface, validated replacement transaction and AtomicFiles RAII
   rollback regression. Show CTest groups and the exact-source CI release provenance.

Core algorithms stay within the documented 256-point educational scope. Reference-verified,
invariant-checked and test-covered statuses mean different things; a large check count is not line
or branch coverage. Use the retained CI coverage report to discuss untested branches.
