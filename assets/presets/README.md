# GeoViz Presets

Drag any `.geoviz` file onto the running application window.

| File | Best lab |
|---|---|
| `hull_cloud.geoviz` | All four convex hulls, closest pair, rotating calipers |
| `delaunay_sites.geoviz` | Delaunay and Voronoi |
| `half_planes.geoviz` | Half-Plane Intersection |
| `crossing_segments.geoviz` | Segment Intersections |
| `concave_polygon.geoviz` | Ear Clipping; append a query point for Point in Polygon |

The format is plain text and versioned. See `docs/ARCHITECTURE.md` for its schema.
